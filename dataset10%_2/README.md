# CVPR-2026-Foundation-Models-for-General-CT-Image-Diagnosis

## Competition Goal

Build a 3D CT Foundation Model applicable to a wide range of clinical diagnosis tasks.

**Coreset Track:**

Train a 3D CT foundation model using only 10% of the CT pretraining data, and evaluate its representation quality via Linear Probing.

**Competition URL:** https://www.codabench.org/competitions/12650/
